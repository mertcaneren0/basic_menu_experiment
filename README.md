# Basic Menu Experiment

A collapsible sidebar menu with drop-down sub-menus.

## What it demonstrates
- Sidebar layout and CSS transitions
- Toggling classes with JavaScript to open and close the menu
- Nested drop-down sub-menus

## Features
- Menu button that collapses the sidebar to icons only
- Arrow icons that expand or collapse sub-menus
- Profile section at the bottom of the sidebar
- Menu links are placeholders (they don't go anywhere)

## Tech
- HTML, CSS, vanilla JavaScript
- Boxicons (from CDN)

## How to run
Open `index.html` in your browser.
